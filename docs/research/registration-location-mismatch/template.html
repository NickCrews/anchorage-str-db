Airbnb listings at a different location than the STR registration they display

Since July 31, 2026, every short-term rental in the Municipality must show its STR Registration Number on its listings. Each registration records the street address of the rental (AMC 10.90.020), so the number on a listing should lead to the place being rented.

We ask the Clerk's Office to check these registrations and confirm which registration covers each rental. Every case below links to the Airbnb listing and the registration's CityView page, and shows both locations on a map.

Three kinds of problem

Likely the wrong number

The number on the listing belongs to a registration somewhere else. Right where the listing is, there is a different registration with a matching name: the same business, the Airbnb host's name, or the listing's title. Likely explanation: the owner has multiple rentals and mistakenly copied the number from another of their rentals.

Suggested fix: Ask the host to fix the listing, to show the matching nearby registration's number. If that registration is for a different unit, this rental needs its own registration.

One number, two places

Several listings show the same number. Some are at the registered address, but this one is somewhere else. The host may be using one registration for a second rental that needs its own.

Suggested fix: Ask the host to register the second rental and show that new number on its listing.

Not at the registered address

No listing that shows this number is near the registered address, and no registration near the listing matches it. The registration may have the wrong address, or the rental may be using a number that isn't its own.

Suggested fix: Ask the registrant where the rental is. If the registered address is wrong, correct the registration. If the listing is a different rental, it needs its own registration.

      How the cases were found

      Sources. Airbnb listings were read from Airbnb's public search and listing pages on . Each listing page shows the registration id the host entered and a map location. Registrations come from the Municipal Clerk's public Short Term Rental Registration Viewer layer, published , which includes the Municipality's geocoded point for each registered address.

      Distance. For each active listing that displays a number in the registry, we measured the distance from Airbnb's map location to the registered address's geocoded point. Airbnb moves most pins by up to about 200 m to hide the exact address; some pins are exact. A listing more than from its registered address is not explained by Airbnb's offset.

      Problems. Each listing is given the first of these that applies:

      1. Likely the wrong number A different registration within 200 m of the listing has a business name that matches the displayed registration's business name, the Airbnb host's name, or the start of the listing's title. Names are compared ignoring case, punctuation and "LLC". A street named in the title, or a number one digit off from the displayed one, is noted as extra evidence but is not enough by itself.
      2. One number, two places Another listing showing the same number is within of the registered address.
      3. Not at the registered address Neither of the above.

      Limits. A host can place an Airbnb pin incorrectly, and the Municipality's geocoder can place a typed address incorrectly; the registered and geocoded addresses are both shown for each case. Name matches are suggestions for review, not confirmations. Listings that show no registration id, or an id not in the registry, are not included.
