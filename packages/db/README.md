# `@anchorage-str-db/db`

The DuckDB database, and the only package that uses DuckDB directly.

- `schema.ts`: the tables, as Drizzle `pgTable` definitions
- `views.ts`: the views, as DuckDB SQL, and `RETIREMENT_GRACE_DAYS`
- `connect.ts`: `connect(path)`, which applies the migrations, checks the
  tables and recreates the views
- `database.ts`: `Database`, a wrapper over one connection with raw SQL,
  `appendRows` for bulk inserts, `transaction`, and `orm` for Drizzle queries
- `drizzle/`: migrations generated by `drizzle-kit` from `schema.ts`

Drizzle has no DuckDB dialect, so the schema uses `drizzle-orm/pg-core` and
[`@duckdbfan/drizzle-duckdb`](https://github.com/leonardovida/drizzle-duckdb)
runs it on DuckDB.

```sh
pnpm --filter @anchorage-str-db/db generate --name <change>
```

See [CONTRIBUTING.md](../../CONTRIBUTING.md#changing-the-schema) before
changing a table.
